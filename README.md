# Freebies Directory for Healthcare Workers

A static, client-side-searchable directory of free resources for healthcare workers: continuing education (CE) courses, scholarships and grants, printables and handouts, and support links. Official links only. Education only &mdash; never medical advice.

Published and maintained by **Asdale Dynamics, LLC** (Indiana, formed October 2026) &mdash; beginner-friendly AI education, books, and practical tools. See [dylanasdale.github.io](https://dylanasdale.github.io).

## Who this is for

Healthcare workers &mdash; nurses, nursing students, and allied health staff &mdash; looking for free, officially sourced CE, scholarships, printable handouts, and confidential support. Maintained by Dylan Asdale, a registered nurse turned AI author and founder of Asdale Dynamics, LLC.

## What's inside

| Category | What you'll find |
|---|---|
| Continuing Education (CE) | CDC TRAIN / CDC Learning Lab, OpenWHO (WHO), ANA free CE |
| Scholarships & Grants | HRSA Nurse Corps, ANA Foundation |
| Printables & Handouts | CDC printable resources, MedlinePlus handouts |
| Support & Crisis Lines | 988 Suicide & Crisis Lifeline, SAMHSA National Helpline, Emotional PPE Project, NIOSH safety topics |

The full directory is also available in Markdown: [`resources.md`](resources.md).

## How to run

This is a static site with no build step and no dependencies. Open `index.html` in any browser, or serve it locally:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

Client-side search and category filtering run entirely in the browser from `resources.json`. No data is sent anywhere.
